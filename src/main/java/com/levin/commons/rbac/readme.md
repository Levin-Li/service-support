### RBAC 核心概念

1. 资源对象 `Res`
   资源有域、类型、资源标识和操作列表

2. 资源操作 `Res.Action`
   通常对应资源类型上的可执行动作

3. 资源许可 `Permission`
   许可对特定资源执行特定操作

4. 角色对象 `Role`
   角色关联权限列表，也可以带数据范围

5. 用户对象 `User`
   用户关联角色，也可以直接带数据范围

6. 权限检查注解 `ResAuthorize`
   可以加在类或方法上，方法上的定义可以覆盖类上的定义

7. 菜单对象 `MenuItem`
   菜单和权限分离，菜单声明自己依赖的权限

### 一句话理解

这一套 RBAC 的重点不是单纯的“用户-角色-权限”，而是把：

- 权限表达式
- 多租户
- 组织树
- 数据机密级别

统一到了一套默认模型里。

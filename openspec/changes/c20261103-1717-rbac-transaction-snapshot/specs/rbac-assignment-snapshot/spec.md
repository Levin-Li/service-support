## ADDED Requirements

### Requirement: 可信事务内角色分配快照

角色分配 MUST 保留原授权及扩展检查，并支持在可信服务端事务中对完整权威角色、领域、目标租户和组织目录进行额外校验；不得使用不完整缓存证明新组织授权。

#### Scenario: 未提交组织缺失于缓存
- **WHEN** 新组织未进入共享缓存而存在于完整事务目录中
- **THEN** 按真实组织和最终角色检查操作者范围，父级仅 Self 时不得授予子组织范围。

#### Scenario: 快照不完整或异常
- **WHEN** 数量不符、缺少目标组织、重复、跨租户或租户无效
- **THEN** 失败关闭并由调用事务回滚。

#### Scenario: 原有覆盖扩展拒绝
- **WHEN** 宿主覆盖原角色分配或数据范围检查并拒绝
- **THEN** 新入口不得绕过该拒绝。

## ADDED Requirements

### Requirement: 关联列兼容同次编译生成的字段常量

实体字段常量处理器 SHALL 保留字面量和编译期常量表达式的注解列名。引用同次生成的 E_ 常量时 SHALL 生成值等价的 T_ 常量，由 Java 编译器验证引用和表达式。无法恢复关联列的源表达式时 SHALL 报出定位到原字段的诊断。

#### Scenario: 自引用和字符串拼接
- **WHEN** 关联列的 name 使用实体自身的 E_ 字段或包含它的常量表达式
- **THEN** 处理器在无旧构建产物时生成 E_，最终注解 name 和 T_ 常量值一致。

#### Scenario: 别名自身依赖同次生成的常量
- **WHEN** name 使用的单独常量别名自身依赖同次编译才生成的 E_
- **THEN** javac 在调用注解处理器前诊断该限制。把 E_ 引用直接写入 name 表达式可通过验证。
